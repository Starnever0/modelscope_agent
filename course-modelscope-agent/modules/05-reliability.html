稳定性设计：出错时系统怎么自救

真正可用的 AI 产品，不是“不出错”，而是“出错后能优雅恢复”。

像导航软件：走错路要自动重规划

router、grade、rewrite 形成了一个有界反馈环：先判读，再检索，不够好就重写一次。配合 兜底策略 与 降级，整体体验会稳定很多。

CODE 

try:
    analysis = router_chain.invoke({"messages": state["messages"]})
    return {
        "rewritten_query": analysis.standalone_query,
        "datasource": analysis.datasource
    }
except Exception as e:
    last_msg = state["messages"][-1].content
PLAIN ENGLISH

先按理想流程走：调用路由链做解析。

如果成功，返回独立查询和数据源选择。

如果失败，不让系统崩掉，而是抓取用户最后一句做保底。

这是典型“先最优，后保活”的工程心法。
