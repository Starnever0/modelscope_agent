检索引擎：语义 + 关键词双保险

看懂混合检索与并行召回，你就能让 AI “找得准、找得快”。

像找书：图书馆检索 + 目录检索同时进行

FAISS 负责“语义相近”匹配，BM25 负责“关键词精确”匹配，然后用加权方式合并结果。

🧠
Aha: 混合检索的本质

单一策略总会有盲区。把“语义理解”和“关键词命中”组合，能更稳地覆盖不同提问习惯。

CODE 

return EnsembleRetriever(
    retrievers=[vector_retriever, bm25_retriever],
    weights=[0.5, 0.5]
)
PLAIN ENGLISH

返回一个“组合检索器”。

它同时使用向量检索器和 BM25 检索器。

两边权重都是 0.5，表示各占一半影响力。

最后输出融合后的候选文档。

并行检索：复杂问题拆分后一起查

CODE 

max_workers = min(len(sub_questions), 8)
with ThreadPoolExecutor(max_workers=max_workers) as executor:
    docs_batches = executor.map(_retrieve_one, enumerate(sub_questions, 1))
PLAIN ENGLISH

最多开 8 个并发工人，防止开太多线程。

在并发池里批量处理每个子问题。

把每个子问题的检索结果收集成批次。
