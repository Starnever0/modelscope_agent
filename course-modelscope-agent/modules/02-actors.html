代码翻译：路由分支是如何声明的

CODE 

workflow.add_conditional_edges(
    "router_node",
    route_after_router,
    {
        "chat_node": "chat_node",
        "decompose_query_node": "decompose_query_node",
    }
)
PLAIN ENGLISH

给工作流添加“条件分流”规则。

当前节点是 router_node。

由 route_after_router 函数算出下一跳。

如果结果是 chat_node，就直接走闲聊。

如果结果是 decompose_query_node，就进入知识问答链路。
